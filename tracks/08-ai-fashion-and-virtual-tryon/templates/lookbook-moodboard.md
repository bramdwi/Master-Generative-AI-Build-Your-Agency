# Spesifikasi Moodboard & Pencahayaan Lookbook Mode

Gunakan templat ini untuk menstandarkan gaya visual, pencahayaan studio, dan pengaturan warna untuk buku tampilan editorial mode.

## 1. Getaran Visual & Pola Dasar Estetika
* **Nama Tema:** misalnya Musim Gugur Minimalis Nordik
* **Palet Inti:** Warna kelabu tua hangat, pasir lembut, warna zaitun kalem, abu-abu.
* **Kata Kunci Suasana Hati:** Editorial, kemewahan yang tenang, organik, arsitektur.

## 2. Koordinat Pencahayaan Studio
* **Lampu Tombol Utama:** Softbox besar yang tersebar dari kiri pada sudut 45 derajat.
* **Cahaya Isi:** Reflektor putih memantul dari kanan untuk memperhalus bayangan leher.
* **Cahaya Latar/Rim:** Cahaya latar hangat yang halus untuk memisahkan bahu model dari latar belakang.
* **Pencahayaan Sekitar:** Siang hari yang mendung lembut.

## 3. Preset Latar Belakang Lingkungan
* [ ] Siklorama mulus berwarna putih murni
* [x] Layar plester bertekstur berwarna abu-abu hangat
* [ ] Kolom beton arsitektur
* [ ] Layar partisi kayu modern abad pertengahan

## 4. Matriks Token Cepat
Gabungkan token berikut untuk menghasilkan latar belakang lookbook:

```
[Model Archetype] + [Garment Descriptors] + [Studio Lighting Specs] + [Camera Settings]
```

* **Arketipe Model:** `Editorial fashion model standing in a relaxed pose,`
* **Deskripsi Pakaian:** `wearing a minimalist neutral-toned organic knit sweater,`
* **Spesifikasi Pencahayaan Studio:** `diffused side studio softbox lighting, soft neutral shadows,`
* **Pengaturan Kamera:** `shot on medium format Hasselblad 80mm lens, f/4, crisp details, natural skin textures.`
