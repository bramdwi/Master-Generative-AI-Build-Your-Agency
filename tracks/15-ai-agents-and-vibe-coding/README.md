# Track 15: Agen AI & Vibe-Coding untuk Kreator

> Agen pengkodean (Claude Code, Cursor, dan sejenisnya) menghilangkan hambatan "Anda harus sudah menjadi pengembang" — jalur ini mengajarkan pembuat konten untuk membuat dan menjual alat mikro mereka sendiri, bukan hanya media yang dihasilkan AI.

---

## 🗺️ Ikhtisar Kurikulum

| # | Modul | Konsep Inti | Keluaran / Hasil |
|---|---|---|---|
| 1 | [What Coding Agents Actually Do](01-what-coding-agents-actually-do.md) | Kemampuan agen, jendela konteks, terminologi non-pengembang | Model mental & pengaturan lingkungan untuk pengkodean getaran |
| 2 | [Building Your First Sellable Micro-Tool](02-building-your-first-sellable-micro-tool.md) | Definisi cakupan, aplikasi tujuan tunggal, API pembungkus (Replikasi, ElevenLabs) | Prototipe aplikasi web alat mikro yang berfungsi dan dapat diterapkan |
| 3 | [The Vibe-Coding Workflow](03-vibe-coding-workflow.md) | Prompt → Bangun → Uji → Perulangan pengiriman, debugging melalui agen, hindari penyebaran kode | Basis kode alat mikro yang teruji dan bebas kesalahan siap untuk dihosting |
| 4 | [Pricing & Selling Tools You Build](04-pricing-and-selling-tools.md) | Akses seumur hidup vs. langganan bulanan, pass-through biaya API, integrasi Lemon Squeezy/Stripe | Strategi monetisasi & halaman penjualan langsung untuk alat Anda |
